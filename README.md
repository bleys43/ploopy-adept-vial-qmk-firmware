# ploopy-adept-vial-qmk-firmware
ploopy adept vial firmware binaries and source tree for building them.

NON-MAC USERS ONLY:
ploopyco_madromys_rev1_001_bleys43-vial_highres_scroll.uf2 - high resolution scroll firmware, with invert scroll and momentary scroll enabled

MAC USERS CAN USE THESE:
ploopyco_madromys_rev1_001_bleys43-vial-semphore_4.uf2 non- high resolution scroll firmware, with invert scroll and momentary scroll enabled
ploopyco_madromys_rev1_001_bleys43-vial-toggle-scroll-semphore_4.uf2 - toggle-scroll version of the above firmware

madromys/ - source files for building these firmwares
